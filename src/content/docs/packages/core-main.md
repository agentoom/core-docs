# `@agentoom/core-main`

The foundational package providing the application backbone, agent construction runtime, and pipeline engine.

---

## 🚀 Key Modules

- **Agent Runtime**: Dynamic construction of agents with prompt instructions, registered capabilities, knowledge files, and AI model routing.
- **Pipeline Orchestrator**: Executes multi-step workflows with conditional branching and data interpolation.
- **Job Queue Dispatcher**: Enqueues workloads with prioritization, concurrency locks, and exponential retry backoff.
- **Project Isolation**: Multi-tenant resource separation and credit budgeting.
