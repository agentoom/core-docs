# `@agentoom/core-compliance`

Implements the legal and regulatory framework required by the European Union AI Act.

---

## 🏛️ Core Features

- **GovernanceGate**: Pre-execution check verifying agent risk status before model inference.
- **AiAgentTrace**: Tamper-evident execution logs with SHA-256 integrity signatures.
- **Emergency Stops**: Instant administrative kill-switches.
- **Evidence Package Generator**: Creates `.zip` audit archives for compliance officers.
