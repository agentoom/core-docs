# Users, Roles & Access Control

Agentoom implements granular Role-Based Access Control (RBAC) via standard permissions.

---

## 👥 Built-in Roles

- **Superadmin**: Full access to all platform settings, server configuration, system workers, and projects.
- **Admin**: Full access to create agents, configure compliance profiles, and manage project members.
- **Operator**: Authorized to chat with agents, approve Sentinel pending decisions, and monitor live queues.
- **Viewer**: Read-only access to dashboards, logs, and telemetry.
