# Live Support: Seamless Human Takeover

When a customer conversation becomes emotional, complex, or requires sensitive dispute resolution, `@agentoom/core-live-support` enables human operators to intervene without dropping the session.

---

## 🤝 How Human Takeover Works

1. **Automatic Escalation Triggers**: An agent detects user frustration or explicit requests like *"I want to speak with a human"*.
2. **Operator Alert**: A real-time notification alerts the support desk in the Command Center.
3. **Session Interception**: The human support agent clicks **Take Over**. The AI agent is paused, and the customer transitions to chatting with the live human operator seamlessly inside the same widget window.
4. **Handoff Back to AI**: Once resolved, the operator can return the session to the AI assistant with a single click.
